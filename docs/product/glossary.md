# Glossário

- **Experimento:** registro local de uma hipótese ou atividade técnica; não contém dados pessoais.
- **Especificação:** declaração versionada do comportamento e das restrições esperadas.
- **Contrato:** interface verificável entre componentes, como OpenAPI ou esquema Zod.
- **Evidência:** teste, relatório ou inspeção que demonstra um requisito.
- **Fatia vertical:** incremento pequeno que atravessa interface, API e domínio.
- **SDD:** Specification-Driven Development; especificações governam plano, tarefas e implementação.
